# @personaai/adapters 0.2.0

`@personaai/adapters` is the **unified adapter package** for Persona. It provides native, first-class bindings for Express, Next.js, and NestJS, wrapping the framework-agnostic [`@personaai/runtime`](/docs/runtime/v0.10.0) engine with zero duplicated logic.

Instead of managing separate adapter packages, `@personaai/adapters` ships as a single package with framework-specific subpath exports sharing a high-performance transport core.

> **Server-Side Only:** Adapter route handlers hold your Persona Project API credential. Never import adapter server entrypoints into browser bundles.

```bash
npm install @personaai/adapters
```

## Why a Unified Package?

Prior to `0.2.0`, each framework was published as an isolated package (`@personaai/express`, `@personaai/nextjs`, `@personaai/nestjs`). While functional, this introduced version drift and duplicate logic across streaming backpressure, multipart handling, and header translation.

`@personaai/adapters` unifies all adapters into a single package:
1. **Shared Core Internals (`src/shared/`):** Stream writers with transport backpressure (`res.write` drain listeners), multipart parsing for file attachments, header sanitization, and error translation are written once and shared across all hosts.
2. **Single Dependency:** Install `@personaai/adapters` once in your monorepo or project. You only need peer dependencies for the framework you actually use (e.g. `express`, `next`, or `@nestjs/common`).
3. **Zero Deprecation Friction:** The legacy individual packages are now deprecated shims that forward directly to `@personaai/adapters`.

## Installation & Peer Dependencies

Install the core package:

```bash
npm install @personaai/adapters
# or
pnpm add @personaai/adapters
# or
yarn add @personaai/adapters
```

### Install Only What You Use

Peer dependencies are strictly optional. Install only the framework you are deploying:

```bash
# For Express applications
npm install express

# For Next.js applications
npm install next react

# For NestJS applications
npm install @nestjs/common @nestjs/core reflect-metadata rxjs
```

## Quick Example by Framework

### Express
```ts
import express from 'express';
import { createExpressAdapter } from '@personaai/adapters/express';

const app = express();
app.use(express.json());

const { router } = createExpressAdapter({
  baseUrl: process.env.PERSONA_BASE_URL!,
  credential: process.env.PERSONA_CREDENTIAL!,
  resolveUserFrom: (req) => req.user?.id ?? null,
});

app.use('/api/persona', router);
```

### Next.js (App Router)
```ts
// app/api/persona/[...persona]/route.ts
import { createPersonaHandler } from '@personaai/adapters/nextjs/server';
import { auth } from '@clerk/nextjs/server';

export const { GET, POST, PUT, PATCH, DELETE } = createPersonaHandler({
  baseUrl: process.env.PERSONA_BASE_URL!,
  credential: process.env.PERSONA_CREDENTIAL!,
  resolveUserFrom: async () => (await auth()).userId,
});

export const dynamic = 'force-dynamic';
```

### NestJS
```ts
// app.module.ts
import { Module } from '@nestjs/common';
import { PersonaModule } from '@personaai/adapters/nestjs';

@Module({
  imports: [
    PersonaModule.forRoot({
      baseUrl: process.env.PERSONA_BASE_URL!,
      credential: process.env.PERSONA_CREDENTIAL!,
      resolveUserFrom: (req) => req.user?.id ?? null,
      routePrefix: '/api/persona',
    }),
  ],
})
export class AppModule {}
```

## Migration from Legacy Shims

If your codebase currently imports from `@personaai/express`, `@personaai/nextjs`, or `@personaai/nestjs`, migrate to `@personaai/adapters` with a simple import path update:

```diff
- import { toExpressRouter } from '@personaai/express';
+ import { toExpressRouter } from '@personaai/adapters/express';

- import { createPersonaHandler } from '@personaai/nextjs/server';
+ import { createPersonaHandler } from '@personaai/adapters/nextjs/server';

- import { PersonaModule } from '@personaai/nestjs';
+ import { PersonaModule } from '@personaai/adapters/nestjs';
```

Then uninstall the legacy package:
```bash
npm uninstall @personaai/express @personaai/nextjs @personaai/nestjs
npm install @personaai/adapters
```
