# `PersonaSandboxCommand`

One ``execute`` tool call against an Agent's sandbox (real shell execution in an isolated CodeSandbox VM — requires the Agent's ``sandboxEnabled`` and a ``CSB_API_KEY`` Project Secret; see the Agent's ``sandboxEnabled`` field). Derived from ``PersonaToolCall``s named ``execute`` across every message in the conversation, in stream order — not a separate live/history-tracked state, so it's always consistent with ``messages``.
