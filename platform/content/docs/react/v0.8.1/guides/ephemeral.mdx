# Ephemeral new chat (0.8.1)

**Problem:** `createThread` on New Chat left empty threads (`threads[0]` = newest empty) and required `ensureThreadId: Promise` wrapper for first send.

**Solution:** `threadId: undefined` is a true ephemeral state.

```tsx
const [threadId, setThreadId]=useState<string|undefined>()
const {threads, refetch}=useThreads(true)
const chat=useChat({
  agentId, threadId, voice,
  onThreadCreated:(id)=>{ setThreadId(id); refetch() },
  onTitle:()=> refetch(),
})

const handleNewChat=()=>{ chat.startNewChat(); setThreadId(undefined) }
const handleSend=(t?:string)=> chat.sendMessage(t) // auto POST /threads if ephemeral
```

`displayThreads` merges optimistic `New chat` + `optimisticTitles` + server `threads` so list never flashes `Loading…` — see `swasthsaathi-01` `chat-app.tsx:168`.
