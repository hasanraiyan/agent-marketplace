All hooks are client-side React hooks (`'use client'`). Every one must be called inside a
`<PersonaProvider>` — they read `fetchWithAuth` and `defaultAgentId` from context.

## Workflows Hooks

### `useWorkflowStream`

The primary workflow execution hook — manages streaming execution of multi-step workflows, tracks node progression states live, supports cancellation, and allows stream resumption across disconnects.

```tsx
import { useWorkflowStream } from '@personaai/react';

const {
  status,
  isRunning,
  activeNodeId,
  nodeRuns,
  output,
  text,
  error,
  start,
  cancel,
  resume,
  reset,
} = useWorkflowStream(workflowId, {
  onNodeStarted: (node) => console.log('Node started:', node.nodeLabel),
  onNodeCompleted: (node) => console.log('Node completed:', node.nodeId),
  onNodeFailed: (node) => console.error('Node failed:', node.error),
  onFinish: (result) => console.log('Workflow complete:', result),
  onError: (error) => console.error('Stream failed:', error),
});
```

#### Return Value
- `status`: `'idle' | 'running' | 'completed' | 'failed' | 'cancelled'`
- `isRunning`: `boolean` (true when status === 'running')
- `activeNodeId`: `string | null` (the node currently executing)
- `nodeRuns`: `Record<string, PersonaNodeRunState>` (live map of all executed and in-flight nodes with input, output, duration, and status)
- `output`: `unknown` (final workflow return value)
- `text`: `string` (accumulated assistant message text deltas from Agent steps)
- `error`: `Error | null`
- `start(input?, options?)`: Triggers a workflow execution (`POST /workflows/:id/stream`)
- `cancel()`: Sends cancellation request (`POST /workflows/runs/:runId/cancel`) and aborts connection
- `resume(runId, sinceSeq?)`: Reconnects to an interrupted run via `GET /workflows/runs/:runId/resume?since=<seq>`
- `reset()`: Resets all hook state back to idle

### `useWorkflows`

List, paginate, search, and create workflows.

```tsx
import { useWorkflows } from '@personaai/react';

const {
  workflows,
  pagination,
  isLoading,
  error,
  refetch,
  createWorkflow,
} = useWorkflows({ search: 'invoice', page: 1, limit: 10 });
```

#### Options
- `autoFetch`: `boolean` (default `true`)
- `search`: `string`
- `status`: `'draft' | 'published' | 'archived'`
- `page`: `number`
- `limit`: `number`

### `useWorkflow`

Manage a single workflow: fetch details, inspect published versions, export Mermaid flowcharts, save drafts, publish new versions, and delete.

```tsx
import { useWorkflow } from '@personaai/react';

const {
  workflow,
  versions,
  mermaid,
  isLoading,
  error,
  refetch,
  saveDraft,
  publish,
  fetchMermaid,
  fetchVersions,
  deleteWorkflow,
} = useWorkflow(workflowId);
```

---

### `useWorkflowRuns`

List execution history for a workflow, inspect individual run metrics, and cancel in-flight executions.

```tsx
import { useWorkflowRuns } from '@personaai/react';

const {
  runs,
  pagination,
  isLoading,
  error,
  refetch,
  getRun,
  cancelRun,
} = useWorkflowRuns(workflowId);
```

## Agent & Chat Hooks

### `useChat`

Primary chat conversation hook — streaming messages, thread history loading, human-in-the-loop (HITL) approval, clarification questions, workspace files/todos, and ephemeral new-chat state.

```tsx
import { useChat } from '@personaai/react';

const {
  messages,
  input,
  setInput,
  handleSubmit,
  sendMessage,
  isStreaming,
  stop,
  reload,
  interrupt,
  resumeInterrupt,
  startNewChat,
  isEphemeral,
} = useChat({ agentId, threadId });
```

---

### `useVoice`

Real-time full-duplex voice sessions powered by Gemini Live.

```tsx
import { useVoice } from '@personaai/react';

const {
  state,
  isMuted,
  transcript,
  partial,
  toolCalls,
  start,
  stop,
  mute,
} = useVoice({ agentId, threadId });
```

---

### `useThreads`

Thread CRUD operations: list, create, delete, rename, reset, and archive conversations.

```tsx
import { useThreads } from '@personaai/react';

const {
  threads,
  isLoading,
  createThread,
  deleteThread,
  renameThread,
  resetThread,
} = useThreads();
```

---

### `useFiles`

Upload and download file management (`POST /files` and `GET /files`).

```tsx
import { useFiles } from '@personaai/react';

const {
  files,
  uploadFile,
  deleteFile,
  isUploading,
} = useFiles();
```

---

### `useMemory`

Read and write persistent memory surviving across threads and sessions (`GET /memory` and `PUT /memory/file`).

```tsx
import { useMemory } from '@personaai/react';

const {
  memory,
  getFile,
  writeFile,
  deleteFile,
} = useMemory();
```

---

### `useAgents`

Agent discovery — query public and private agents.

```tsx
import { useAgents } from '@personaai/react';

const { agents, isLoading, refetch } = useAgents();
```

---

### `useConnection`

Probes backend connectivity and capabilities via `GET /health`.

```tsx
import { useConnection } from '@personaai/react';

const { isConnected, health, checkHealth } = useConnection();
```

---

### `useMcp`

Access MCP resources and trigger MCP tools for interactive Ext App widgets.

```tsx
import { useMcp } from '@personaai/react';

const { readResource, callTool } = useMcp({ mcpId });
```

---

## `PersonaProvider`

Root context provider wrapping your application:

```tsx
import { PersonaProvider } from '@personaai/react';

<PersonaProvider
  baseUrl="http://localhost:3000/api/persona"
  getAuthToken={async () => getSessionToken()}
  defaultAgentId="agent_123"
>
  {children}
</PersonaProvider>
```
