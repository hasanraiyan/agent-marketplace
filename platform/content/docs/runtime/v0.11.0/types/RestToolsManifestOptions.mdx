# `RestToolsManifestOptions`

Serves a list of code-defined REST tools (built with ``defineRestTool`` from ``@personaai/sdk/rest-tools``) as a JSON manifest at ``GET {mountPath}/rest-tools/manifest`` — register that URL in the Persona dashboard as a REST Tool Source and it discovers/calls these tools live, the same way it discovers an MCP server's tools. This is host-side static data the runtime *serves*, not a Persona-proxy capability — it never calls ``PersonaClient`` and works even with no ``resolveUser`` traffic at all.
