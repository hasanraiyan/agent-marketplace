# `RuntimeHooks`

Lifecycle hooks — the host application's voice inside the runtime's request handling. Plain async event listeners, not middleware: the runtime proceeds with sensible defaults when a hook is omitted, and a hook that wants to reject a run simply throws (the throw is caught and routed through the same sanitized error path as any other failure).
