# `RuntimeCapabilities`

Every one of these is ``false`` unless explicitly enabled — always-off by default so upgrading this package never silently exposes new surface to whoever ``resolveUser`` accepts. These resources are Project-level configuration (LLM provider credentials, skill/knowledge-base/vector-store management, security audit logs, an agent-building co-pilot) rather than things an end user does in a chat session — most hosts should manage them via ``@personaai/sdk`` directly from their own admin surface and never turn these on. Turn one on only if you specifically want it reachable through whatever ``resolveUser`` gates (which may not be "any logged-in end user" — that's your call).
