# Agents

`client.agents` → `POST/GET/PATCH/DELETE /api/v1/developer/agents`

## Types

`Agent { _id, name, systemPrompt, providerId, modelName, skills: string[]|Skill[], mcps: string[]|Mcp[], knowledgeBases: string[]|KnowledgeBase[], storeMounts, visibility: 'public'|'unlisted'|'private', interruptOn, category, socialLinks }`

`CreateAgentInput { name, systemPrompt, providerId, visibility?, skills?, mcps?, knowledgeBases? }` — `name/systemPrompt/providerId` required. `skills`/`mcps`/`knowledgeBases` are bare id arrays on create/list, populated objects on `get`.

## Methods

### create(input, idempotencyKey?) → Agent
```ts
const agent = await persona.agents.create({
  name: 'Career Launchpad',
  systemPrompt: 'You help students',
  providerId: 'prov_123',
  visibility: 'unlisted',
  skills: [skill._id],
}, 'idem-key-1'); // Idempotency-Key header
```

### list(params?) → PaginatedResult<Agent>
```ts
const { items, pagination } = await persona.agents.list({ page:1, limit:20, search:'career', scope:'mine' });
```
`DiscoverAgentsParams { page?, limit?, search?, category?, scope?:'mine' }`

### get(agentId) → Agent
Populated `skills`/`mcps`/`knowledgeBases` as objects.

### update(agentId, input) → Agent
Partial — arrays **replace** (not merge).

### delete(agentId) → void / bulkDelete(ids) → BulkDeleteResult `{deleted: string[], failed: {id,reason}[]}` up to 100.

### getMcpConnections(agentId, returnTo?) → McpConnection[]
Per-user OAuth status for `authType:oauth authMode:user` MCPs — **requires `externalUserId`** client (see [Auth](/docs/sdk/v0.7.5/guides/auth)).
