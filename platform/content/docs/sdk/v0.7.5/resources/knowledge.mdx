# Knowledge

`client.knowledge` → `/api/v1/developer/knowledge` — Qdrant, chunk `chunkSize/chunkOverlap`, `topK` search.

```ts
const kb = await persona.knowledge.create({ name: 'Docs', providerId: 'prov_123', config: { chunkSize: 1000 } });
const up: UploadDocumentsResult = await persona.knowledge.uploadDocuments(kb._id, [{ path: 'handbook.pdf', content: buf, mimeType: 'application/pdf' }]); // up to 10 files, 20MB
const docs: KnowledgeDocument[] = await persona.knowledge.listDocuments(kb._id);
const hits: KnowledgeSearchResult[] = await persona.knowledge.search(kb._id, 'refund policy', { topK: 5 });
await persona.knowledge.deleteDocument(kb._id, 'handbook.pdf');
```
