# Skills

`client.skills` → `/api/v1/developer/skills`

`Skill { _id, name, description, instructions, files: SkillFile[] }` — `instructions` is the reusable prompt chunk agents `skillIds` mount.

```ts
const skill = await persona.skills.create({ name: 'Refund policy', description: '...', instructions: 'Always ...' });
const { items } = await persona.skills.list({ search: 'refund' });
await persona.skills.update(skill._id, { instructions: 'Updated ...' });
const usage: ResourceUsage = await persona.skills.getUsage(skill._id); // {agentCount, agents: [{_id,name}] 20 cap}
await persona.skills.bulkDelete([skill._id]);
```
