# Stores

`client.stores` → `/api/v1/developer/stores` — named mounts generalization of memory (`/stores/<name>/`).

```ts
const store = await persona.stores.create({ name: 'my-store', scope:'project', accessMode:'readwrite' });
await persona.stores.writeFile(store._id, { path: 'hello.txt', content: 'hi' });
const files: StoreFile[] = await persona.stores.listFiles(store._id);
```
