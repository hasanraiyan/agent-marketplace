# Threads

`client.threads` → `/api/v1/developer/threads` — **requires `externalUserId`** (see [Auth](/docs/sdk/v0.7.5/guides/auth)). `Thread { _id, threadId (AG-UI), agentId, title?, isArchived?, createdAt, updatedAt }` — `threadId` (AG-UI) ≠ `_id`.

## Methods

### create(input) → Thread
```ts
const thread = await userClient.threads.create({ agentId: agent._id });
```
Explicit thread; `chat` can also implicitly create (ephemeral) — see [React ephemeral](/docs/react/v0.8.1/guides/ephemeral).

### list(params?) → PaginatedResult<Thread> — recent first, `agentId` populated

### get(threadId), update(threadId, {title?, isArchived?}), updateTitle(threadId, title), delete(threadId), reset(threadId) → Thread (same id, cleared messages/files/traces), bulkDelete(ids)

### getMessages(threadId) → ThreadMessages
```ts
const { messages, state, subagentTraces, pendingInterrupt } = await userClient.threads.getMessages(thread._id);
```
`state: { files, todos }` + `subagentTraces: Record<toolCallId, trace>` + `pendingInterrupt: {kind:'hitl'|'clarification'}` for `ChatResume`.

Interlinked: [Chat stream](/docs/sdk/v0.7.5/resources/chat) uses `threadId`; [Voice](/docs/sdk/v0.7.5/resources/voice) mints ticket with `threadId` to persist voice turns back into same thread.
