# Auth

`PersonaClient` is **server-side only** — `credential` is `"<keyId>.<secret>"` minted in Developer Studio → Project → Credentials. Never construct it in a browser bundle or `"use client"` component.

```ts
import { PersonaClient } from '@personaai/sdk';
const persona = new PersonaClient({
  baseUrl: 'https://api.persona.hasanraiyan.me',
  credential: process.env.PERSONA_CREDENTIAL!,
});
```

## whoami — sanity check

```ts
const who = await persona.whoami();
// { principalType: 'ProjectMachine' | 'ProjectRuntime', domain, projectId }
```

If `credential` is wrong you get `PersonaAuthError` before any resource call.

## Acting on behalf of your own user

Most resources (`threads`, `files`, `chat`, `memory`, `voice`) are **per-external-user**. Create a second client per request:

```ts
const userClient = new PersonaClient({
  baseUrl: 'https://api.persona.hasanraiyan.me',
  credential: process.env.PERSONA_CREDENTIAL!,
  externalUserId: currentUser.id, // your own id
});
const thread = await userClient.threads.create({ agentId: agent._id });
for await (const e of userClient.chat.stream(agent._id, { messages: [{ role:'user', content:'Hi' }] })) {}
```

Control-plane resources (`providers`, `agents`, `skills`, `knowledge`, `mcps`, `restTools`, `stores`, `auditLogs`) ignore `externalUserId` — they are Project-scoped.
