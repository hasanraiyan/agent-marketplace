# Files

`client.files` → `/api/v1/developer/files` — distinct from `useChat files` (workspace).

```ts
const file = await userClient.files.upload({ file: formDataFile, agentId: agent._id });
const { items } = await userClient.files.list({ page:1, limit:20 });
const res: Response = await userClient.files.download(file.id);
await userClient.files.bulkDelete([file.id]);
```
