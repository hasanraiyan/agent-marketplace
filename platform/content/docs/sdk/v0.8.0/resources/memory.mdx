# Memory

`client.memory` → `/api/v1/developer/memory` — file-based memory `/memories/user/` + `/memories/agent/`.

```ts
const list: MemoryListResult = await userClient.memory.list();
await userClient.memory.writeFile({ path: 'prefs.json', content: JSON.stringify({ lang:'en' }), scope:'user' });
await userClient.memory.deleteFile({ path: 'prefs.json' });
```
