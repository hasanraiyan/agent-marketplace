# Providers

`client.providers` → `/api/v1/developer/providers` — control-plane only (no `externalUserId`). `Provider { id (not _id), name, baseUrl, modelName, apiKey: never returned }`

```ts
const p = await persona.providers.create({ name: 'OpenAI', baseUrl: 'https://api.openai.com/v1', apiKey: 'sk-...', modelName: 'gpt-4o' });
const list: Provider[] = await persona.providers.list(); // bare array
await persona.providers.testConnection(p.id);
const models: ProviderModel[] = await persona.providers.getModels(p.id);
```
