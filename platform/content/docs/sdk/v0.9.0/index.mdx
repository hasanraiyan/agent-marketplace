# @personaai/sdk 0.9.0

Node.js/TypeScript SDK for the Persona Developer Platform API — Agents, Skills, Knowledge, MCP, Stores, memory, and streaming chat **from your own backend**.

> **Server-side only.** `PersonaClient` holds your Project credential — never construct it in a browser bundle or client component. See [Concepts: Credentials](/concepts/credentials).

## Install

```bash
npm install @personaai/sdk
# peer (optional, only for rest-tools): npm install zod
```

Requires Node 18+.

## Quickstart

```ts
import { PersonaClient } from '@personaai/sdk';

const persona = new PersonaClient({
  baseUrl: 'https://api.persona.hasanraiyan.me',
  credential: process.env.PERSONA_CREDENTIAL!,
});

// Sanity-check
const who = await persona.whoami();

// Provision an Agent (control-plane)
const agent = await persona.agents.create({
  name: 'Career Launchpad',
  systemPrompt: 'You help students find internships.',
  providerId: '...',
  visibility: 'unlisted',
});

// Per-request, assert an external user
const userClient = new PersonaClient({
  baseUrl: 'https://api.persona.hasanraiyan.me',
  credential: process.env.PERSONA_CREDENTIAL!,
  externalUserId: currentUser.id,
});

for await (const e of userClient.chat.stream(agent._id, {
  messages: [{ role: 'user', content: 'Hi' }],
})) {
  if (e.type === 'TEXT_MESSAGE_CHUNK' && e.delta) process.stdout.write(e.delta);
}
```

See [Quickstart](/docs/sdk/v0.9.0/quickstart) for the full first-chat walkthrough.
