# memory

> **Auth:** Requires `Authorization: Bearer <keyId>.<secret>` (server-side). For per-user calls add `x-persona-external-user-id`. See [Credentials](/concepts/credentials).

Memory is a file-based store: `/memories/user/` (shared) and `/memories/agent/` (per user-agent). Agents read/write via `write_file`/`read_file`.

## Example

**TypeScript**

```ts
const list = await userClient.memory.list();
await userClient.memory.writeFile({ path: '/memories/user/preferences.md', content: '# Likes\n- concise answers' });
```

**cURL**

```bash
curl https://api.persona.hasanraiyan.me/api/v1/developer/memory/file?path=/memories/user/preferences.md \
  -H "Authorization: Bearer $PERSONA_CREDENTIAL" -H "x-persona-external-user-id: user_123"
```

**Response**

```json
{
  "success": true,
  "data": { "path": "/memories/user/preferences.md", "content": "# Likes" }
}
```
