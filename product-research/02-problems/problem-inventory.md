## 🚀 Startup Thinker — Problems (⚠️ ARCHIVED)

### ST-P1: Idea Validation Uncertainty

| Field                   | Detail                                                                                                                |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Problem Statement**   | Founder has a startup idea but cannot confidently determine whether it solves a real problem that people will pay for |
| **User Context**        | Alex (or similar founder) has an exciting idea but no structured way to validate it                                   |
| **Trigger**             | Idea excitement → peer skepticism → self-doubt                                                                        |
| **Current Behavior**    | Asks friends/family (biased), posts on Reddit (unstructured), asks ChatGPT (generic)                                  |
| **Current Alternative** | Lean Canvas (static), YC videos (passive), startup forums (noisy)                                                     |
| **Pain/Frustration**    | High — fear of wasting months building something nobody wants                                                         |
| **Frequency**           | Every time they have a new idea (weekly/monthly)                                                                      |
| **Severity**            | Critical — determines whether they build or pivot                                                                     |
| **Evidence**            | Research confirms: "build-first mistake" is common; founders struggle with objective validation                       |
| **Assumptions**         | Founder would use an AI agent instead of free alternatives                                                            |
| **Desired Outcome**     | Clear, objective, structured validation with actionable next steps                                                    |
| **Validation Status**   | Not validated with real users                                                                                         |

| **Frequency**           | Continuous during validation phase                                                                                |
| **Severity**            | High — leads to false confidence                                                                                  |
| **Evidence**            | Well-documented cognitive bias in startup literature                                                              |
| **Assumptions**         | An AI challenger can effectively counteract this bias                                                             |
| **Desired Outcome**     | Receive objective, challenging questions that force honest evaluation                                             |
| **Validation Status**   | Not validated                                                                                                     |

## 🌍 Study Abroad Navigator — Problems (⚠️ ARCHIVED)

### SA-P1: No Single Source of Truth for the Journey

| Field                   | Detail                                                                                                                                                                                |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Problem Statement**   | Students face a fragmented 18-24 month process with information spread across university websites, scholarship portals, visa offices, forums, and spreadsheets — with no unified view |
| **User Context**        | Priya is starting from zero and doesn't know what she doesn't know                                                                                                                    |
| **Trigger**             | Decision to study abroad → immediate overwhelm                                                                                                                                        |
| **Current Behavior**    | Opens dozens of browser tabs, creates messy spreadsheets, saves PDFs everywhere                                                                                                       |
| **Current Alternative** | Study abroad consultants ($500-$5,000), Reddit, YouTube                                                                                                                               |
| **Pain/Frustration**    | Very High — information overload, fear of missing critical steps                                                                                                                      |
| **Frequency**           | Continuous over the entire journey                                                                                                                                                    |
| **Severity**            | Critical — missed deadlines = missed opportunities                                                                                                                                    |
| **Evidence**            | Research confirms: no integrated tool exists; process is fragmented across 5+ distinct phases                                                                                         |
| **Assumptions**         | Students would trust a single AI platform for the entire journey                                                                                                                      |
| **Desired Outcome**     | One dashboard tracking profile, universities, scholarships, deadlines, documents, and visa status                                                                                     |
| **Validation Status**   | Not validated                                                                                                                                                                         |

| Field                   | Detail                                                                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |

| **User Context**        | Priya has a limited budget and her family needs clear cost projections                                                                     |
| **Trigger**             | Researching universities → discovering wildly different costs                                                                              |
| **Current Behavior**    | Uses scholarship search sites (overwhelming, not personalized), asks forums                                                                |
| **Current Alternative** | Fastweb, Scholarships.com (generic, not personalized)                                                                                      |
| **Pain/Frustration**    | High — financial toxicity is #1 barrier                                                                                                    |
| **Frequency**           | Throughout the journey, peaks during application season                                                                                    |
| **Severity**            | Critical — determines whether study abroad is possible at all                                                                              |
| **Evidence**            | Research confirms: financial toxicity is #1 barrier for international students                                                             |
| **Assumptions**         | AI can provide personalized, accurate cost estimates and scholarship matches                                                               |
| **Desired Outcome**     | Clear cost breakdown + personalized scholarship matches + loan guidance                                                                    |
| **Validation Status**   | Not validated                                                                                                                              |

## 💼 Career Launchpad — Problems

### CL-P1: Unclear Career Direction

| Field                   | Detail                                                                                                                                              |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Problem Statement**   | Students/graduates don't know which career path fits their skills, interests, and background — so they apply to everything and connect with nothing |
| **User Context**        | Jordan is graduating soon and doesn't know what direction to pursue                                                                                 |
| **Trigger**             | Approaching graduation → "what now?" panic                                                                                                          |
| **Current Behavior**    | Applies to anything remotely relevant (spray-and-pray)                                                                                              |
| **Current Alternative** | Career counselors (limited availability), LinkedIn (passive), friends/family (biased)                                                               |
| **Pain/Frustration**    | High — feels lost, directionless                                                                                                                    |
| **Frequency**           | Daily during job search                                                                                                                             |
| **Severity**            | High — wrong direction wastes years                                                                                                                 |
| **Evidence**            | Research confirms: career uncertainty is a major source of graduate anxiety                                                                         |
| **Assumptions**         | AI can help students discover career paths they hadn't considered                                                                                   |
| **Desired Outcome**     | Clear career path recommendations based on actual skills and interests                                                                              |
| **Validation Status**   | Not validated                                                                                                                                       |

### CL-P2: Skill Gap Uncertainty

| Field                   | Detail                                                                                                    |
| ----------------------- | --------------------------------------------------------------------------------------------------------- |
| **Problem Statement**   | Students don't know what skills are actually required for their target career, and whether they have them |
| **User Context**        | Jordan sees job descriptions with skills they've never heard of                                           |
| **Trigger**             | Reading job descriptions → feeling inadequate                                                             |
| **Current Behavior**    | Guesses which skills to learn, asks ChatGPT for advice                                                    |
| **Current Alternative** | Generic "learn to code" advice, bootcamp marketing                                                        |
| **Pain/Frustration**    | High — "should I learn Python? Figma? SQL? AWS?"                                                          |
| **Frequency**           | Every time they look at job postings                                                                      |
| **Severity**            | High — investing time in the wrong skills is wasted effort                                                |
| **Evidence**            | Research confirms: skills gap between education and employer needs is well-documented                     |
| **Assumptions**         | AI can compare actual job market data with the student's current skill set                                |
| **Desired Outcome**     | Personalized skill gap analysis with prioritized learning roadmap                                         |
| **Validation Status**   | Not validated                                                                                             |

### CL-P3: No Honest Feedback on Resumes & Portfolios

| Field                   | Detail                                                                                                           |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Problem Statement**   | Students submit dozens of applications and hear nothing back — recruiters won't tell them why they were rejected |
| **User Context**        | Jordan has applied to 50+ jobs, heard back from <5                                                               |
| **Trigger**             | Application ghosting → frustration                                                                               |
| **Current Behavior**    | Keeps applying with the same resume, hoping for different results                                                |
| **Current Alternative** | ChatGPT resume tips (generic), university career center (underfunded, limited hours)                             |
| **Pain/Frustration**    | Very High — feels invisible, hopeless                                                                            |
| **Frequency**           | Every application cycle                                                                                          |
| **Severity**            | Critical — a bad resume hides all other qualifications                                                           |
| **Evidence**            | Research confirms: ghosting is a major frustration for graduates                                                 |
| **Assumptions**         | AI can provide specific, honest resume feedback that recruiters won't give                                       |
| **Desired Outcome**     | Specific, actionable resume/portfolio feedback with before/after examples                                        |
| **Validation Status**   | Not validated                                                                                                    |

### CL-P4: Interview Anxiety & Unpreparedness

| Field                   | Detail                                                                                                     |
| ----------------------- | ---------------------------------------------------------------------------------------------------------- |
| **Problem Statement**   | Students don't know what to expect in interviews, how to prepare, or whether their answers are good enough |
| **User Context**        | Jordan finally gets an interview and is terrified of blowing it                                            |
| **Trigger**             | Interview invitation → panic                                                                               |
| **Current Behavior**    | Watches generic "how to ace the interview" videos                                                          |
| **Current Alternative** | Mock interviews with friends (not realistic), YouTube (generic), paid interview prep (expensive)           |
| **Pain/Frustration**    | High — one chance to make an impression                                                                    |
| **Frequency**           | Each interview opportunity (infrequent but high-stakes)                                                    |
| **Severity**            | High — a failed interview wastes the application effort                                                    |
| **Evidence**            | Consistent theme across career guidance communities                                                        |
| **Assumptions**         | AI can simulate realistic interview scenarios with honest feedback                                         |

| **Validation Status**   | Not validated                                                                                              |
