# @personaai/sdk — docs source

Source MDX for `@personaai/sdk` lives here and is published into `platform/content/docs-v2/sdk/v{version}/` via `platform/scripts/snapshot-docs.mjs`.

- `guides/*.mdx` — hand-written tasks (auth, chat, workflows, …). Single source of truth for guide prose.
- Generated `resources/*.generated.mdx` and `types.mdx` live ONLY in the published snapshot in `platform/content/docs-v2/` — never hand-edited here.

See `plan.md` §6 and §9 for the full repo architecture.
