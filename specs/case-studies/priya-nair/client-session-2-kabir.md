Ship 2 Projects in 8 Weeks — Beginner PM Track (APM prep)

Principles
- Build in public. Post weekly updates with numbers.
- Solve narrow, real problems where you can reach users fast.
- Bias to shipping: smallest slice that delivers value each week.
- Measure 1 primary metric per project (activation, retention, or revenue proxy).

Your output at the end
- 2 live links + 2 Loom walkthroughs (2–3 mins each)
- 2 one‑pagers with problem, users, scope, metrics, and learnings
- A short project portfolio site/Notion page linking all of the above

Week‑by‑week plan
Week 0 (prep — 1–2 days)
- Pick two problem spaces where you have access to 20–50 users (e.g., campus societies, local small businesses, student housing, exam prep).
- Define success metrics: Project A → activation (first value) rate; Project B → 7‑day retention.
- Recruit a small advisory group (5–7 target users) and 1 engineer/design buddy each.

Week 1 — Problem discovery & scope
- 8–10 user interviews per project (30 mins, record notes). Identify top 2–3 jobs‑to‑be‑done and current hacks.
- Write a one‑pager for each: problem, users, 2 must‑have use cases, top risks, metric, and a 2‑week V1 scope.

Week 2 — V1 build & ship (MVP)
- Spec the MVP in plain language + 1 flow diagram. Timebox engineering to 1 week.
- Ship a testable V1 to 10–20 users. Instrument basic analytics (Mixpanel/GA, or simple event logging to a Google Sheet).

Week 3 — Measure + iterate
- Review activation funnel and top 3 drop‑offs. Run 2 quick experiments (copy, onboarding step removal, default choices).
- Post update: V1 numbers, what changed, next 3 fixes.

Week 4 — V2 slice
- Prioritize 1–2 high‑leverage features based on data. Cut the rest.
- Ship V2. Expand to 30–50 users. Add qualitative feedback (2 user clips in Loom).

Week 5 — Growth loop / retention
- Instrument 1 simple loop: referral nudge, notification, or weekly value email.
- Run 1 user‑level retention experiment (e.g., saved views, reminders, streaks).

Week 6 — Monetization (lightweight) or impact proxy
- If B2C: test a waitlist with a paid tier mock ($3–$5/mo) or a one‑time $1 in‑app purchase using Gumroad/Stripe test.
- If B2B: pilot a paid plan with 2 local businesses; define a value metric (hours saved, leads captured) and get a testimonial.

Week 7 — Polish + storytelling
- Fix top UX papercuts. Add empty‑state copy, tooltips, and a crisp landing page.
- Record 2–3 min Looms per project. Write one‑pagers with before/after metrics.

Week 8 — Launch + distribution
- Post on LinkedIn, relevant subreddits/communities, and school channels. Ask 5 mentors/alumni for feedback posts.
- Convert learnings into 3–5 STAR stories: prioritization tradeoff, execution under constraint, metric movement, cross‑functional alignment.

Templates to create (copy into Notion/Docs)
- One‑pager template
  - Problem
  - Target user and JTBD
  - V1 scope (2 weeks max)
  - Metric and instrumentation
  - Risks/assumptions
  - Results (numbers + quotes)
  - Next steps
- Spec template (plain language)
  - Goal
  - User flow (1 diagram)
  - Acceptance criteria (5–8 bullets)
  - Non‑goals
  - Analytics events
- Update template (weekly)
  - Week X summary
  - What shipped
  - Metric snapshot
  - Top 3 issues
  - Next 3 changes

Project ideas with fast user access
- Campus: room‑mate chore tracker with reminders; lab equipment booking optimizer; placement prep tracker with peer accountability; campus events filter with RSVP reminders.
- Local SMB: WhatsApp‑to‑Google‑Shee
